# Aster Device Manager — Admin Guide (excerpt, fictional)

## Kiosk Lockdown Mode

Administrators can restrict a device to a curated set of approved
applications. Once lockdown is applied, workers cannot open unapproved apps,
change device settings, or exit to the home screen without an administrator
PIN.

## Remote Wipe & Lock

From the admin console, an administrator can send a remote lock or a full
wipe command to any enrolled device. A wiped device returns to factory
settings and is removed from the fleet inventory automatically.
